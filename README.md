# 📊 스마트 시험 감독 배정 (웹 버전)

설치 없이 **링크만 열면** 쓰는 시험 감독 배정 프로그램입니다. 서버가 없고, 모든 계산과 저장은 각자의 브라우저 안에서 이루어집니다.

- 입력한 내용은 **브라우저에 자동 저장**됩니다. 같은 PC, 같은 브라우저로 다시 열면 그대로 남아 있습니다.
- **💾 백업 파일 저장** 버튼으로 모든 자료(설정·과목·교사·예외·배정 결과·직접 고친 칸)를 `.json` 파일 하나로 받고, **📂 백업 불러오기**로 복원합니다.
- 예전 파이썬 프로그램의 `DATA SAVE` 파일(`부광고_배정셋팅_백업.json`)도 그대로 불러올 수 있습니다. 과목명 뒤의 `*(장소)` 표기는 추가반 버튼으로 자동 변환됩니다.
- 화면 위쪽의 1~4단계 표시로 진행 상태를 보며 차례로 입력하고, 각 단계의 **?** 또는 상단 **설명서**에서 자세한 안내를 볼 수 있습니다.
- 결과는 예전과 같은 3개 시트(결과_감독표 / 결과_시수표 / 결과_개인별시간표) 엑셀로 저장합니다. 다음 회차에서 이 파일로 누적 시수를 불러옵니다.

## 링크로 배포하기 (GitHub Pages)

1. 이 브랜치를 `main`에 병합합니다.
2. 저장소 **Settings → Pages**에서 **Source: Deploy from a branch**, **Branch: `main` / `(root)`**를 고르고 저장합니다.
3. 1~2분 뒤 `https://08hwichemi.github.io/exam-proctor/` 주소로 열립니다. 이 링크를 선생님들께 전달하면 됩니다.

> 엑셀 라이브러리(ExcelJS)는 `vendor/` 폴더에 들어 있습니다. 학교망에서 외부 CDN이 막혀 있어도 동작합니다.

## 사용 순서

| 단계 | 하는 일 |
|---|---|
| 1. 기본 설정 | 회차, 옵션(같은 교실 금지, 3학년 담임 연간 보정 등), 학년별 반 수, 시험 일차·교시 |
| 2. 시험 과목 | 교시별 과목, 자습 / 제외 반 번호, **+ 추가반** 버튼(장소 입력) |
| 3. 교사 명단 · 예외 | 엑셀 불러오기·붙여넣기, 구분(일반/고사담당/원로/순회/제외), 목표시수, 이전 누적 / 특수실 지정자, 일차·교시별(또는 종일) 예외 감독자 |
| 4. 배정 결과 | 배정 → 칸을 눌러 직접 수정(📌 고정) → 다시 돌리기 → 엑셀 저장 → 누적 반영 |

## 배정 방식

**반드시 지키는 규칙**: 같은 교시 1자리, 본인 과목 시험 시간 제외, 담임은 본인 반 교실 제외, 예외 감독자 제외, 특수실 지정자 제외, 3교시 연속 금지, 고사담당은 1교시만, 순회는 시험 교실 제외(복도·자습만), 원로는 복도·자습 제외 + 목표시수/하루 상한까지, 제외 교사 및 (4차) 3학년 담임·부장 제외, (옵션) 같은 교실 두 번 금지.

**고르게 맞추는 것** (중요한 순서): 감독 부족 없음 → 목표시수 초과 없음 → 원로 목표 채우기 → 일반 교사 전체 누적 시수 차이 → 복도+자습 / 교실 시수 차이 → 하루에 몰리지 않게 → 연속 교시 줄이기 → 같은 교실 반복 줄이기.

예전 프로그램은 "무작위로 순서를 정해 한 칸씩 채우기"를 500번 반복해 가장 나은 결과를 골랐습니다. 새 엔진은 같은 방식으로 초안을 만든 뒤, **수십만 번 감독을 바꾸거나 맞바꿔 보며** 점수가 좋아지는 쪽으로 다듬습니다(담금질 기법). 가상 학교 데이터(80명, 3일×3교시)로 비교하면 두 방식 모두 부족·위반이 0이었고, 새 엔진이 일반 교사 누적 시수 차이를 매번 1시간씩 더 줄였습니다(예: 8~13 → 8~12). 계산 시간은 1~2초입니다.

직접 고친 칸은 📌로 고정됩니다. **다시 돌리기**를 하면 고정한 칸은 그대로 두고 나머지만 다시 맞춥니다.

### 검증 결과 (`node tests/verify.js`)

가상 학교(교사 55·62·70·85명, 7반×3학년, 3일 시험)로 돌린 결과입니다.

**① 더 좋은 방법이 있는가?**
엔진이 찾은 누적 시수 차이를 "이론상 가장 고른 분배(하한선)"와 비교했습니다. 하한선은 누적이 적은 선생님부터 가능한 교시만큼 채웠을 때의 차이로, 어떤 알고리즘도 이보다 좋을 수 없습니다.

| 교사 수 | 하한선 | 엔진 결과 (시드 6개) | 반복 ¼ / ×3 |
|---|---|---|---|
| 55명 | 3 | 4, 4, 4, 4, 4, 4 | 4 / 4 |
| 62명 | 3 | 3, 3, 3, 3, 3, 3 | 3 / 3 |
| 70명 | 2 | 2, 2, 2, 2, 2, 2 | 2 / 2 |
| 85명 | 1 | 1, 1, 1, 1, 1, 1 | 1 / 1 |

네 경우 중 셋은 하한선과 같고, 55명 사례의 1시간 차이는 하한선 계산에 들어 있지 않은 "3교시 연속 금지" 때문에 생기는 것으로 보입니다(반복을 3배로 늘려도, 시드를 바꿔도 같은 값). 남아 있는 차이는 규칙 때문입니다. 예를 들어 영어 시험이 8교시 중 6교시에 있으면 영어 교사는 2교시밖에 못 들어가고, 고사담당은 1교시에만 들어갑니다. 시수표의 **"가능 교시"** 열에서 이런 선생님을 확인할 수 있습니다.

**② 1~4차 연간 누적이 맞춰지는가?** (4차는 3학년 시험 없음)

| | 연말 일반 교사 누적 (62명) | 3학년 담임 |
|---|---|---|
| 4차에 3학년 담임 제외 | 11~15 | 11~12 (3시간 적음) |
| 4차에도 3학년 담임 감독 | 14~15 | 14~15 |
| 제외 + **연간 보정 1시간** | 13~15 | 13~14 |
| 제외 + 연간 보정 2시간 | 13~17 | 14~17 (지나침) |

4차에 3학년 담임을 빼면 그분들만 연말 합계가 3시간쯤 적습니다. 학교 원칙은 **4차에 빠지는 교사는 3차까지의 평균으로 본다**는 것이므로 기본값은 보정 없음(0)입니다. 연말 합계까지 맞추고 싶을 때만 "3학년 담임 연간 보정"을 1로 두면 차이가 1~2시간으로 줄고, 4차에도 감독하게 하면 1시간 안으로 맞춰집니다.

**③ "한 번 들어간 교실 다시 안 들어가기" 규칙**
이번 시험 안에서든, 올해 이전 회차 교실까지 포함하든 **부족 자리 0, 시수 차이 변화 없음**이었습니다. 교사 1명이 한 시험에 교실 3~4번, 1년에 12번쯤 들어가는데 교실은 21개라 여유가 큽니다. 예전 프로그램에서 자리가 모자랐던 것은 "한 칸씩 순서대로 채우는" 방식이 막다른 길에 갇혔기 때문입니다. 기본값으로 켜져 있습니다(이번 시험 안에서).

## 예전 파이썬 프로그램 점검 결과

웹 버전에서 모두 고쳤습니다.

1. **반이 7개까지만 배정됨**: 반 수를 8 이상으로 입력해도 8반부터는 아무 표시 없이 빠졌습니다.
2. **예외 감독자 교시를 `1교시`로 적으면 적용 안 됨**: 숫자 `1`만 인식했습니다. 이름이나 교사 구분 뒤에 공백이 붙어도(`제외 `) 적용되지 않았습니다. → 교시는 목록에서 고르고, 이름은 명단에서 고르며, 명단에 없는 이름은 빨갛게 표시합니다.
3. **1교시 고사담당은 예외·특수실·연속 규칙을 건너뜀**: 조건문 들여쓰기 문제였습니다.
4. **이름 없는 추가반(`*`)에 자습/제외 버튼을 같이 누르면 장소 이름이 "자습:1"이 되고 자습 지정이 사라짐**.
5. **자습 버튼만 모두 누른 학년은 "전체 자습"으로 인식 안 됨**: 과목 칸에 `자습`이라고 적었을 때만 인식했습니다.
6. **과목이 빈 칸도 시험 감독 7명 + 복도 2명을 배정함** → 빈 칸은 "시험 없음"으로 보고 감독을 넣지 않으며, 점검 목록에 알려 줍니다.
7. **특수실 시수 칸이 쓰이지 않음** → 그 선생님 시수에 더합니다.
8. **교사 엑셀은 열 순서가 정확히 맞아야 했음** → 머리글(이름·과목·담임·구분·목표시수)로 찾습니다.
9. **"제외 입력 시 창 깜빡임"**: 화면이 없는 환경이라 직접 재현하지는 못했습니다. PyQt 표 안에 버튼 묶음을 넣고 열 너비를 "늘이기(Stretch)"로 둔 구조라서, 표 크기와 스크롤바가 서로를 계속 다시 계산하며 깜빡였을 가능성이 높습니다. 웹 버전은 버튼을 누를 때 그 칸만 다시 그리고, 글자를 입력하는 동안에는 화면을 다시 그리지 않습니다.
10. **시험 과목과 교사 과목명 표기가 다르면(예: `수학Ⅰ` ↔ `수학`) 본인 시험 시간에도 배정됨** → `수학` 교사는 `수학Ⅰ`, `수학Ⅱ`, `수학(미적)` 시험과 같은 과목으로 봅니다. 그래도 맞는 교사를 찾지 못한 시험 과목은 점검 목록에 표시합니다.
11. 라이선스 키(비밀 단어)는 공개 저장소에 그대로 노출되어 있었습니다. 웹 버전에서는 암호를 없앴습니다.
